Semantic HTML

Introduction

Why use semantic tags?

The <div> tag is a very commonly used tag to group elements together, however there are tons of tags whose dedicated purpose is just to group other elements together. There is <section>, <article>, <aside> just to name a few. These all behave identically to <div> tags. So why use them? Although they dont strictlly speaking provide any new functionality they're primarly used to provide meta data about what type of content is on your page. This helps both with SEO as well as helping those who use screen readers. Another help is that semantic HTML tags help you as a programmer better understand your own code by using tags that describe the content and purpose within your tags. 

<html>
  <head>
    <!--some meta data stuff-->
    ...
  </head>

  <body>
    <header> <!--usually navigation and maybe a logo-->
      ...
    </header>

    <main> <!--for the main content of the page-->
      <section> <!--first of many sections-->
        <h2>some heading<h2>
            <article> <!--some text based content!-->
            ...

    </main>

    <footer> <!--for the main content of the article-->
      ...
    </footer>

  </body>
</html>

List of semantic tags and their purposes

Tag Purpose
<address> is for an adress usually in the footer
<article> The article tag is for a piece of text content that can be understood on its own
<aside> aside is for a piece of text that adds something to say an article
<code> code is used when the content is code
<figure> This is for an image or other figure
<figcaption> used inside the <figure> tag to give a figure a caption
<footer> The footer sits at the bottom of the page with additional information, like contact info
<header> The header sits at the top of the page usually with some navigation
<main> The main content of the page, usually everything but the header, footer and navigation
<nav> The website navigation, usually a bunch of links that live in the header
<section> A larger section that contains other things like articles and asides and headings that belong together
<span> A piece of inline text usually to style specifically as part of other text
<time> Simply; date and time
The bolded elements here are the main larger structures of the webpage. the rest are smaller or more individual elements

Default stylings

I may have lied earlier, some semantic elements do in fact serve a specific purpose. You may notice the <span> tag being mentioned to be inline by default. <span> are among the semantic elements that have some default behaviour, typically. You see the rest all have a default styling; <em> emphizes text by making it italic by default, <strong> makes text bolded, <mark> makes text highlighted as if with a highliting pen. <q> and <blockquote> are both used for quotes, <blockquote> typically having some margins and <q> having quotation marks around it. lastly there is <details> which makes the text by default collapsable, and <summary> which can be used to spcify how the collapsed text will read.
